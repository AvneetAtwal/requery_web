# Requery Web

An intermediate-level static webpage with a dark sage green and beige color scheme.

## Features

- Responsive design
- Smooth scrolling navigation
- Interactive contact form
- CSS animations and transitions
- Modern layout with sections for Home, About, Services, and Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Deployment on Netlify

1. Push this repository to GitHub.
2. Go to [Netlify](https://netlify.com) and sign in with your GitHub account.
3. Click "New site from Git" and select this repository.
4. Netlify will automatically detect it as a static site and deploy it.
5. Your site will be live at a URL like `https://your-site-name.netlify.app`.

## Local Development

To run locally:

1. Clone the repository
2. Open `index.html` in your browser

No build process required - it's a static site!
